# Logic pass

Check that everything the item states, computes or accepts is true for the cited source and
edition. Read with the source open, not from memory. This pass scores Correctness and
Coverage.

## Procedure

1. Open each cited page (`pages` on the block or step). Confirm every definition, theorem
   condition, claim and number against it; note the page when it differs.
2. Recompute every number with code: worked examples, trace frames and their `state`
   rows, table cells, plot points and marked values, answers, hints, distractor values
   and the numbers inside option feedback.
3. Solve each question and exercise step yourself before reading its key. Each correct
   option must be the only correct one; each wrong option must be wrong for exactly the
   reason its feedback gives.
4. List the conventions an answer depends on (tie-breaks, order of neighbours, goal test,
   indexing, units, rounding). Each must be stated before the task, or every valid
   alternative accepted.
5. Compare each visual with the numbers in its text: a trace frame shows the state its
   caption claims; a plot's marked point lies where the text says.
6. Coverage: every outcome the coverage ledger assigns to the unit is taught and then
   practised; an exercise answers every part of the original. Whether an exercise links
   the passage it needs is scored in the [course pass](course.md).

## Findings

Name the claim, the source page and the correct value: "Trace frame 4 (`block:5`) says
the queue holds B, C; with alphabetical ties it holds C, B (page 12)."

## Mistakes found in real courses

- A trace that skips an operation, so a value changes between two frames without a step.
- Feedback that explains the right answer instead of the mistake that leads to the wrong one.
- A convention stated only in the solution, after the student needed it.
- A number copied from a slide of another edition.

Review Explore claims, calculations and citations too. Optional status does not
relax correctness. Confirm the core explanation and tasks remain sufficient with
Explore closed; a true historical fact is not automatically optional. See
[the classification rule](../../prepare-study/references/explore.md).
