# PDF inspection

Keep the original PDF unchanged, including forms and layout. Structural validation
is separate from text extraction; missing OCR does not invalidate a sound PDF.
`studocu_get_document` reads bounded physical pages. Request page images when
formulas, charts, tables or scans need visual evidence. Sparse or incomplete text
is not proof that a page is blank. Cite actual page numbers and disclose uncertainty;
OCR is optional and recognition errors need visual review.
