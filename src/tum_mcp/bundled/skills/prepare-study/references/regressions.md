# Regression lookup

Read rows relevant to changed behavior or a failure. For an unmodified bundled
renderer, reuse known checks and verify new course content; do not repeat this
whole matrix for each unit. These failure modes remain part of the design contract.

| Area / prior failure | Check |
| --- | --- |
| Mobile outline opens offscreen | From far down a lesson, open the outline: it fills the viewport immediately, scrolls independently and blocks background interaction. Close/Escape restores reading scroll and menu focus; selecting a topic closes it and starts that topic at the top. Check focus wrapping and the desktop breakpoint. |
| Inline variables look like raw text | Use `\( ... \)` consistently in prose/glossaries/tables/cards/questions. Native inline MathML preserves subscripts and context, while code/currency/comments remain literal. Check narrow layouts, safe markup, compiled data, activity comments and answer-review dialogs. |
| Revision leaf alignment | Expanded topics reserve the same disclosure gutter as category rows; checkboxes at the same depth align on phone and desktop, including mixed root topics and folders. |
| Feedback action and disclosure spacing | Try again has a visible neutral outline and 44px target. Expanded Other options sits close beneath its label without losing the label’s touch target. |
| Formula loses content | Fractions, matrices, sums, powers and chained equalities preserve all terms at 320/390/800/1440px, after outline toggles and resizing back. Auto-fit uses readable math tokens; indivisible overflow stays horizontally scrollable from its beginning. No observer loop or page overflow. |
| Revision picker becomes unwieldy | Collapse the whole picker and nested categories separately. Category checkboxes select descendants while closed; mixed states and counts remain correct. Disclosure does not change selection, and expansion survives view switches. |
| Reviewing a miss loses results | End-of-set rows have a visible boundary, Review label and chevron, then open a modal without changing route, current question, saved answers or progress. Close/Escape restores row focus and scroll. Unanswered items reveal answers only on Show answer. |
| Mobile unit opens midway down | Scroll to end, navigate to another unit; its beginning is visible. Cover phone document scroll and desktop main-pane scroll. Picking a unit from the phone outline collapses it; the title sits just below the sticky bar. |
| Lost place | Home Start/Continue returns to the last visited unit and view. Next step follows Content → Flashcards → Practice → next unit and never repeats the tabs. |
| Tabs point to nonexistent panels | All aria-controls targets exist, including inactive panels; one panel shown; arrow/Home/End keys select/focus correctly. |
| Skip link resets route | From a nonfirst unit/view, skip to main without changing unit/view. |
| Replacement loses focus | Card arrows and ratings focus the replacement card; practice navigation, retry and Continue focus the new question legend; Check answer focuses the feedback heading. Scope that lookup to the replaced activity: revision has a separate topic-selector legend. Outline collapse/expand retains a usable control and reveals current ancestry. |
| Practice arrows feel detached | Group both arrows in the position/topic header above the question, never in a distant footer. At narrow widths and with long topics, keep targets together and metadata readable. Check first/last bounds, retained answers and visible question focus after navigation, in unit and revision practice. Keep radio arrow keys native. |
| Practice dead end | A checked question shows Try again and Continue and no disabled Check button. The last question adds End of set with buttons to every incorrect or unanswered question. Chosen and correct options are labelled in words and glyphs, not color alone. |
| Hidden outline cannot reopen | Hover anywhere along either boundary reveals its midpoint arrow; Tab reveals it without hover. Collapsed outline leaves no rail. Touch/mobile keeps a visible control without covering reading text. |
| Pooled revision corrupts progress | Use original unit/revision/item identity, including duplicate item keys across topics. Ratings/checked answers agree with the original unit; changing selection from the last item resets position/reveal, preserves checkbox focus and never clears results. Empty selection, reload and both revision tabs work. |
| Review mode drifts | To review pools only cards rated Again and wrong answers in the selected topics, with an accurate count after selection or rating changes. A Got it or a correct retry drops the item on the next entry. Leaving review never deletes progress. |
| Category selection drifts | Nested category toggles affect every descendant and no unrelated topic. Individual edits update parent checked/mixed state immediately. Persist topic IDs, then derive category state on reload; checkbox Space must not flip the card. |
| Typography drift | Headings, reading text, controls, cards and questions use the same primary sans family; only code and mathematical notation use their specialist stacks. Labels stay sentence case. In Chrome the used fonts are the bundled ones (code is never Courier), and no font is requested from another origin. |
| Theme flash / color-only instructions | Colors switch immediately. Captions use active/highlighted/state descriptions, not dark/green; meaning survives either theme. |
| Card faces bleed through | In WebKit and Chromium only one face is visible after each flip, including after several flips; reduced motion swaps faces instantly. |
| Wide content overflows | No page-wide horizontal scroll. Table/formula/code regions scroll by keyboard; labels and notation stay legible at narrow widths/zoom. At 390px a whole diagram is visible without sideways scrolling and its labels stay readable. |
| Table labels split into letters | Check short row labels and asymmetric prose at phone/tablet/desktop, expanded/collapsed outline and zoom. Auto-size columns around whole words; keep genuinely wide tokens in local keyboard-scrollable regions, with no page overflow. |
| Long names stretch outlines | Stress course AND unit titles with unbroken identifiers. Inspect sidebar, phone bar, home topic rows and main content. |
| Hidden storage failure | Block storage, rate/answer; memory-only study works and its warning is visible on home and unit views, also on mobile. |
| Feedback is lost or attached to the wrong text | Select prose/table/code within one section; save/cancel, reload and locate the quote. Duplicate passages need unambiguous context. Changed/missing passages retain their original note with a clear status. Cover keyboard/touch, literal hostile text, edits, reset, resolution and a browser/agent write conflict; keep the draft on failure and never report it saved early. |
| Comments feel detached or cover controls | No top comments button or bottom list. Open from the inline marker/highlight to the exact quote; do not repeat the highlighted quote (retain it for missing passages, and keep unchecked feedback quotes hidden). Check phone/desktop and zoom, long/multiple notes, edge clamping, scroll/resize, Escape/outside dismissal and focus return. Markers have one icon/count surface and a 44px target; never nest them inside card buttons. Scope counts to the current original item in both pooled views, retain resolved/missing-text notes, and keep popup keys from flipping/moving cards. |
| Comment syncing disrupts study | External add/edit/resolve/delete appears without Refresh; unchanged conditional responses preserve DOM, focus, open actions, selection and scroll. Pause hidden. A changed target retains the draft, disables Save and offers Use latest/Keep mine; deletion stays explicit. An unrelated record may rebase once, never overwrite a changed target. Keep rows compact and overflow actions keyboard/touch usable. |
| Activity notes target the wrong item | Selection on cards/options does not flip/choose an answer. Capture the current selection when Comment is clicked, including a quick adjustment. Test front/back, options/feedback and navigation to another item; pooled and original views share the same note. Returning to feedback never preselects or grades an answer. |
| Unrelated change resets progress | Adding a binding preserves course namespace; moving folders retains existing unit labels/revisions and progress on reload. Revised units get separate answers; reset leaves other courses intact. |
| Answer leaks / unintended advance | Card faces alternate visually and in the accessibility tree; sources/ratings require reveal. Only a rating or an arrow advances a card; nothing advances on a timer. Space/1/2/arrows work only in the right context and respect modifiers/inputs/tab arrows. Practice feedback remains until Try again. |
| Plausible wrong trace | Independently compute ordering, frontier, discovery versus processing and directed endpoints. First/last controls are bounded; no autoplay. |
| Valid key, invalid teaching | Verify every changed option/assumption; compare prose, formulas, tables and cards. Repair ambiguity rather than force an answer. |
| Update destroys edits / hides stale material | In a disposable copy, change source/template; sync/build preserves/reports edits and rejects affected stale units. Review before rebinding hashes. |
| Distracting admin copy | Visible text serves study/navigation. Coverage details are concise disclosures; storage errors conditional; no duplicated labels, repeated view links, banners or boilerplate tips. Key hints appear only for fine pointers. |
| Screenshot masks broken behavior | Observe keyboard, feedback, persistence and navigation on the actual app, plus console/asset errors; a successful click is insufficient. |
| QA dominates implementation | Reuse renderer, data-derived selectors and input-stamped evidence. Avoid question × viewport × theme multiplication and recapturing unchanged cases. |
