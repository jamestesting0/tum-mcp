# Component contracts

Read the rows for the component you change. [Regressions](regressions.md) lists the
failures these contracts prevent; [design](design.md) owns tokens, layout and motion.

| Component | Contract |
| --- | --- |
| Course home | Default route (`#home` or no hash). Eyebrow with the semester, course title, the content.json introduction, one primary Start/Continue link to the last visited view (else the first unit), and a Review link with the missed-item count when any exist. Topics follow course order, grouped by path, with minutes and plain status: "Not started", "Practice 2/3 correct", "Cards 3/4 known". A Reset progress icon ends the page and opens a confirm dialog with Cancel and Reset; neither is the Enter default. |
| Outline | The course title links home. Units follow one lecture/week/topic organization; optional path folders open along the current ancestry. Once practice starts, a unit shows "n/m answered", then "n/m correct" when all are answered. Revision is a separate destination. The theme icon sits at the end. On phones, the outline opens as a fixed viewport dialog with independent scroll, background inertness, trapped focus and Escape close; preserve reading scroll. Desktop boundary: midpoint arrow on hover/focus with a 44px hit target and 24px neutral surface, a 12px invisible hover strip along the full edge, always visible for coarse pointers. |
| Unit header | Content shows the path/label eyebrow with minutes, the title, the summary and a visible Objectives list. Flashcards and Practice keep only the eyebrow and title. |
| Views | Top semantic tabs with real panels and roving arrow/Home/End keys; counts in tab labels. |
| Next step | One link after the active view, never repeated tabs: Content → Flashcards → Practice → the next unit's Content. The last unit leads to Revision; revision cards lead to revision practice. Eyebrow "Next", title in the primary typeface, small detail (count or minutes), arrow glyph. A same-unit target switches the view and focuses its tab. |
| Revision | Outline destination. The whole topic checklist and each nested category collapse independently. Leaf rows reserve the disclosure gutter so topic and category checkboxes align at the same depth. Category disclosure arrows have separate 44px targets from the select-all checkbox; closed categories show selected/total counts. Preserve expansion while moving between revision views. Category boxes select or clear every descendant with native indeterminate state; topics, selected/total count, Select all and Clear. A two-option segmented control switches between All items and To review · n. Review pools only cards rated Again and questions answered incorrectly in the selected topics, in course order, and starts those questions unanswered. Only Flashcards and Practice tabs. Each item shows its original topic. Empty states: "Select topics to start revising.", or a specific "No cards marked Again…" / "No incorrect answers…". Pooled items keep their original unit/revision/item keys; deselecting never deletes progress. |
| Source | One small muted line after a section, revealed answer or feedback: "Source: Title · locator", linked for real sources and labelled "Synthetic source" in demos. No personal or contact data. |
| Formula | Use `\( ... \)` for inline variables in teaching prose, glossary, tables and activities. Author display LaTeX; build compiles it locally to safe native MathML. Reflow top-level chained relations into complete lines and fit them to the available container width, between the math type tokens. Never split a fraction, matrix or parenthesized group. Resize and outline changes restore the appropriate layout; genuinely indivisible wide expressions stay keyboard-scrollable with their start visible. Keep a readable equivalent, symbol glossary, assumptions and interpretation. No formula images or external math service. Legacy MathML is accepted for older projects. |
| Diagram | Accessible SVG plus a description. The viewBox is cropped to the drawing's height and fits the column width; below 600px the SVG text grows so labels stay legible after scaling. Steps have explicit captions, labelled state and grouped previous/counter/next controls; no autoplay. Concept maps (`state_labels=caption`) show no traversal bookkeeping. |
| Table and code | Tables have a caption plus column/row headers, intrinsic column sizing and normal word wrapping with whole-word minimum widths; the region scrolls only when the table cannot fit. Code is literal, labelled by language and followed by its explanation with paragraph spacing. |
| Flashcard | One large card button flips between Question and Answer in the reading sans (28px, 18px on phones); the front shows a small "Show answer" cue. Sources and ratings sit outside the button and appear after reveal. Again (1) and Got it (2) save the rating and advance to the next card, focus it and announce the move. The last card stays and reports "End of deck: n known, n marked Again" with Start over. Arrows move and Space flips; key hints appear only for fine pointers. The card is tall enough for its longer face. |
| Practice | Header row: compact position/difficulty (for example `1/9 · Application`) and optional topic on the left, adjacent previous/next arrow icons on the right. Question and options at reading size. One native radio group with token-drawn radios, and Check answer, disabled until a choice exists and removed after checking. Checked options carry "Your answer" or "Correct answer" with a check or cross glyph under their text; other options mute. Feedback: a focused Correct/Not quite heading, the chosen feedback, the correct answer when wrong, the explanation, a compact Other options disclosure with its list directly below the label, the source line, then an outlined secondary Try again and primary Continue. The last question adds End of set with the correct count, the not-answered count and an outlined row for each incorrect or unanswered question: prompt, small status, and a visible Review label with chevron. The whole row is the button. |
| Passage comments | Select text, then Comment (Ctrl/Command+Alt+M). An inline marker beside the section heading or the current card/question position opens a modeless popup at the quote. Browser behavior and sync rules: [comments](comments.md). |
| Question review | End-of-set question rows open a read-only modal with the full question, original topic, four options, chosen/correct labels, explanation and source. An unanswered item reveals its solution only after Show answer. Reviewing never changes answers, progress, route or the current question. Close/Escape returns focus and scroll to the triggering row. The close icon stays visible when the dialog scrolls. |
| Storage notice | Shown only when storage fails, also on phones. |
